OBJETIVOS DO PROJETO
1. Objetivo Principal

CONTROLE DE VALIDADE DE ESTOQUE

Desenvolver um sistema capaz de monitorar automaticamente a validade dos produtos em estoque, auxiliando na identificação de itens próximos ao vencimento e reduzindo perdas financeiras no Supermercado Mariano.

2. Objetivos Específicos
  • Implementar cadastro completo de produtos com informações de validade, lote e setor
  • Registrar a entrada de mercadorias no estoque de forma organizada
  • Monitorar automaticamente produtos próximos ao vencimento (até 30 dias)
  • Exibir painel em TV com alertas visuais para a equipe
  • Desenvolver banco de dados relacional utilizando PostgreSQL
  • Garantir interface simples e intuitiva para usuários não técnicos
  • Automatizar a geração de notificações de produtos próximos ao vencimento
  • Centralizar as informações do estoque em um único sistema
  • Reduzir perdas financeiras e desperdício de produtos

FUNCIONALIDADES A SEREM IMPLEMENTADAS
1. Gestão de Produtos e Lotes
  • Cadastro rápido de produtos com suporte a código de barras (EAN)
  • Registro de múltiplos lotes para um mesmo produto
  • Classificação de produtos por setores (ex: Laticínios, Frios, Mercearia)
  • Busca otimizada por nome, código ou fabricante
  • Interface adaptada para uso em computadores do supermercado
2. Monitoramento e Alertas de Validade
  • Verificação automática diária de produtos próximos ao vencimento
  • Alertas visuais classificados por criticidade (ex: 30, 15 e 7 dias)
  • Painel Dashboard otimizado para exibição contínua em TV para a equipe
  • Geração automática de listas de itens que precisam de ação (ex: promoção)
  • Atualização automática da interface após movimentações
3. Controle de Entradas e Saídas
  • Registro ágil de entrada de novas mercadorias atreladas aos seus lotes
  • Baixa de itens por diversos motivos (venda, descarte, avaria, devolução)
  • Cálculo automático do saldo atual em estoque
  • Histórico completo de movimentações rastreáveis por usuário
  • Auditoria simples para correção de inventário
4. Relatórios e Métricas Gerenciais
  • Dashboard com resumo da saúde do estoque e riscos financeiros
  • Relatórios de perdas mensais devido a vencimentos
  • Análise de setores com maior incidência de produtos vencidos
  • Exportação de dados e listagens para formato CSV/Excel
  • Monitoramento da meta de redução de desperdício do supermercado
5. Backend Completo - Entidades Principais
Entidade Propósito
Produto Catálogo central de itens contendo nome, marca e código de barras
LoteValidade Controle específico das datas de vencimento e quantidades em estoque
Setor Categorização física do mercado para direcionar os alertas à equipe certa
Movimentacao Histórico de entradas, saídas e descartes realizados no estoque
Alerta Sistema de registro e status (lido/pendente) das notificações de validade
Usuário Autenticação, controle de acessos e perfis (ex: Gerente, Repositor)
Configuracao Parâmetros do sistema, como quantidade de dias para disparar os alertas

CONCLUSÃO

PROJETO DE CURRICULARIZAÇÃO PARA APROVAÇÃO

O Controle de Validade de Estoque será desenvolvido como projeto de curricularização com excelência técnica e aplicação prática dos conhecimentos adquiridos no curso de Análise e Desenvolvimento de Sistemas.


Escopo do Projeto:

  • Sistema Desktop Completo - Sistema desenvolvido em Python integrado ao PostgreSQL
  • Banco de Dados - PostgreSQL (ambiente de desenvolvimento e produção)
  • Funcionalidades Principais - Gestão de produtos, Monitoramento de validade, Alertas em tela e Relatórios
  • Métricas e Otimizações - Redução de perdas e acompanhamento do ciclo de vida dos produtos
  • Documentação Técnica - PRD, diagramas, código documentado

Cronograma de Desenvolvimento:

  • Duração: 3 meses (focados no desenvolvimento da interface e lógica do sistema)
  • Estrutura: Execução em 4 fases de desenvolvimento técnico
  • Acompanhamento: Validações acadêmicas periódicas com a orientadora
  • Entrega: Sistema funcional em ambiente local para o Supermercado Mariano

Importante: O projeto tem como objetivo o desenvolvimento de um sistema funcional voltado ao controle de validade de estoque. O sistema será apresentado ao stakeholder para avaliação e possíveis sugestões futuras.
